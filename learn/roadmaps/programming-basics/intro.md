This roadmap is for people who have never written a program. Each lesson explains one idea in a few minutes of reading, with every example in both JavaScript and Python, then hands you real problems to solve in the browser. Pick whichever language you like (or both); the coding problems accept either, and five other languages besides.

You'll go from storing a single value to writing your own functions, finding and fixing bugs, and building a small web page with HTML and CSS. A lesson is finished when you've solved its exercises; problems you've already solved elsewhere count.

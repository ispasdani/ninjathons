Binary search isn't only for finding a value in a sorted array. When a question asks for the smallest speed, capacity or distance that works, and anything bigger works too, you can **guess the answer** and let a quick yes/no check tell you whether to go higher or lower.

Each problem this week comes down to two pieces: a check you can run in one pass, and a binary search over the range the answer can be in. Watch the edges of that range, and the totals that pass 32 bits.

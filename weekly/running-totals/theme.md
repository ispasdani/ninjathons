Add up as you go, and a lot of slow questions become fast ones. A **prefix sum** turns "what does this range add up to?" into one subtraction, and its mirror, the **difference array**, turns "add this to a whole range" into two writes.

This week starts with the plain idea, then pairs it with a hash map and finally with a deque. Each problem has a version that's easy to write and far too slow for the large tests: the point is to find the one that isn't.

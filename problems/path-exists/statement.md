A map has `n` towns, numbered `0` to `n - 1`. Each road `[a, b]` in `edges` joins towns `a` and `b` and can be driven **both ways**.

Return `true` if you can drive from `source` to `destination`, and `false` otherwise. A town can always reach itself.

## Constraints

- `1 <= n <= 200000`
- `0 <= edges.length <= 200000`
- `0 <= a, b, source, destination < n`, and `a != b`
- No road appears twice.

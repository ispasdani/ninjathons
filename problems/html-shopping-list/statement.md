Write the HTML for this page so it looks like the target: a main heading, a short line under it, and the list of things to buy, in order.

The CSS is given; you only write HTML. Use the elements a browser expects for each part: a heading for the title, a paragraph for the line of text, and a list for the items. The checks compare which elements are on the page and their text.

## What to build

- The heading **Shopping list**
- The paragraph **For Saturday's picnic.**
- A numbered list: **Bread**, **Cheese**, **Strawberries**, **Lemonade**

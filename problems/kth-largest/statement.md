Given an array of integers `nums` and an integer `k`, return the `k`-th largest value: the value that would be at position `k` (counting from 1) if `nums` were sorted from largest to smallest.

Repeated values count separately: in `[5, 5, 3]` the 2nd largest is 5.

## Constraints

- `1 <= k <= nums.length <= 100000`
- `-10^9 <= nums[i] <= 10^9`

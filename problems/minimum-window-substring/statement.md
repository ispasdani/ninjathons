Return the shortest substring of `s` that contains every character of `t`, **including repeats**: if `t` has two `a`s, the window needs at least two. If several shortest windows exist, return the one that starts first. If there's none, return the empty string.

## Constraints

- `1 <= s.length, t.length <= 100000`
- `s` and `t` contain English letters (upper and lower case are different).

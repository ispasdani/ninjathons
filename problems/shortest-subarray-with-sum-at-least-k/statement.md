Given an array of integers `nums` and an integer `k`, return the length of the shortest non-empty subarray whose sum is at least `k`. If there is none, return `-1`.

A subarray is a run of consecutive elements. Values can be negative.

## Constraints

- `1 <= nums.length <= 100000`
- `-10^5 <= nums[i] <= 10^5`
- `1 <= k <= 10^9`

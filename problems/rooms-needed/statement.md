An office has to host every one of `meetings`, each `[start, end]` running from minute `start` up to minute `end`. A room holds one meeting at a time, and a meeting can start in a room at the minute the previous one there ends.

Return the fewest rooms needed to host them all.

## Constraints

- `1 <= meetings.length <= 100000`
- `0 <= start < end <= 10^9`

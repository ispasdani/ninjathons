Given an array of integers `nums` and an integer `k`, return how many subarrays add up to exactly `k`.

A subarray is a non-empty run of consecutive elements. Two subarrays count separately when they start or end at different positions, even if they hold the same values.

The answer can be larger than a 32-bit integer.

## Constraints

- `1 <= nums.length <= 100000`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

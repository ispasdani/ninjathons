A full-program warm-up: read the input yourself and print the answer.

## Input

The first line holds an integer `n`. The second line holds `n` integers separated by spaces.

## Output

Print the sum of the `n` integers on one line.

## Constraints

- `1 <= n <= 200000`
- Each integer is between `-10^9` and `10^9`.
- The sum can exceed 32 bits: use a 64-bit integer.

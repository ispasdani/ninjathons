Rotate `nums` to the right by `k` steps: each step moves the last value to the front. Return the result.

`k` can be much larger than the length of `nums`.

## Constraints

- `1 <= nums.length <= 200000`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

For an extra challenge, do it in place with O(1) extra memory.

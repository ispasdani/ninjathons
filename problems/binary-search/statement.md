`nums` is sorted in increasing order and has no repeated values. For each value in `queries`, find its index in `nums`, or `-1` if it isn't there.

Return the answers in the same order as `queries`.

## Constraints

- `1 <= nums.length <= 100000`
- `1 <= queries.length <= 100000`
- `-10^9 <= nums[i], queries[j] <= 10^9`
- `nums` is strictly increasing.

Can you answer each query in O(log n) time?

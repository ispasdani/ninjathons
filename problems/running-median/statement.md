Numbers arrive one at a time, in the order of `nums`. After each one arrives, report the median of everything seen so far.

With an odd count the median is the middle value once sorted. With an even count there are two middle values: report the **smaller** one, so every answer is a whole number.

Return the medians, one per number, in order.

## Constraints

- `1 <= nums.length <= 200000`
- `-10^9 <= nums[i] <= 10^9`

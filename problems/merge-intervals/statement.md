`intervals[i] = [start, end]` is a closed range of numbers. Merge every group of overlapping intervals and return the result, sorted by start.

Intervals that only touch, like `[1, 4]` and `[4, 5]`, overlap too.

## Constraints

- `1 <= intervals.length <= 100000`
- `0 <= start <= end <= 10^9`
- The input is in no particular order.

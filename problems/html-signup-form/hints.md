## Hint

Each field is a `<label for="…">` followed by an `<input id="…">` with the same name in `for` and `id`. Wrap each pair in a `<p>` so they sit on their own line, as in the target.

## Hint

The `type` attribute chooses the field: `text`, `email`, `password`, `checkbox`. An email field checks the address, and a password field hides what's typed.

## Hint

`required` and `minlength="8"` are attributes on the input. For the checkbox, put the input before its label.

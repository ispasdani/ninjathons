## Hint
`margin: 0 auto` centres a block that has a width. `max-width: 100%` with `box-sizing: border-box` keeps it inside a narrow page, padding included.

## Hint
`display: flex; align-items: center; gap: 16px;` on the card puts the avatar and the text side by side, vertically centred.

## Hint
A circle is a square with `border-radius: 50%`. Give the avatar `flex-shrink: 0` so the text can't squash it.

Group the words that are anagrams of each other: words made of exactly the same letters, the same number of times each.

Return the groups in this order, so there's one right answer:

- within a group, the words sorted alphabetically (repeated words stay, each once per time it appears);
- the groups sorted by their first word.

## Constraints

- `1 <= words.length <= 10000`
- `0 <= words[i].length <= 100`
- Words contain only lowercase English letters. An empty word is its own anagram.

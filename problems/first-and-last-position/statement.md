`nums` is sorted in non-decreasing order and may contain repeated values. Return the index of the first and the last occurrence of `target`, as `[first, last]`, or `[-1, -1]` if `target` isn't in `nums`.

## Constraints

- `0 <= nums.length <= 100000`
- `-10^9 <= nums[i], target <= 10^9`
- `nums` is sorted in non-decreasing order.

Can you do it in O(log n) time?
